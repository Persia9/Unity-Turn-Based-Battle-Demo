# CUBE BATTLE

敵の次の行動を読み、攻撃・防御・強攻撃を選んで戦う、Unity 製の 1 対 1 ターン制バトルゲームです。三連戦モードと、敗北まで挑戦を続ける無限モードを実装しています。

<details>
<summary>中文对照</summary>

Unity 制作的 1 对 1 回合制战斗游戏。玩家观察敌方预告，选择攻击、防御或强攻击。支持三连战与持续到败北的无限模式。

</details>

## 遊び方

| 行動 | 効果 |
| --- | --- |
| 攻撃 | 敵にダメージを与えます。 |
| 防御 | 次の敵の攻撃によるダメージを軽減します。 |
| 強攻撃 | 大きなダメージを与えます。使用後はクールダウンが発生します。 |

敵の予告から攻撃と防御のタイミングを判断します。次戦へ進む際は HP を回復し、攻撃力・最大 HP・防御性能から強化を選びます。

- **三連戦モード** — 全3戦を勝ち抜き、最後のボス撃破を目指します。
- **無限モード** — 敗北するまで戦闘と強化を繰り返し、到達ラウンドを伸ばします。
- **表示言語** — タイトル画面で日本語と英語を切り替えられます。

<details>
<summary>中文对照</summary>

根据敌方预告决定进攻或防御，强攻击有冷却。续战前回血并强化。三连战以通过三场为目标，无限模式挑战更高轮次，界面支持日英切换。

</details>

## 設計で意識したこと

### 戦闘ルールと画面表示の責務

ダメージ計算と勝敗判定を Domain 層にまとめ、Application 層で操作と進行を調整します。画面は ViewModel を通して状態を表示し、入力を UseCase へ渡します。

<details>
<summary>中文对照</summary>

Domain 管伤害和胜负规则，Application 编排流程，界面通过 ViewModel 显示状态并提交输入。

</details>

### 二つのモードで共通の戦闘処理を使用

単一の戦闘状態は BattleSession、モード・ラウンド・強化などの進行状態は RunSession で管理します。同じバトルシーンを使い、モードに応じてステージと敵の数値を決定します。

<details>
<summary>中文对照</summary>

BattleSession 管单场战斗，RunSession 管模式、轮次和强化。两种玩法共享战斗场景，按规则决定关卡与敌人数值。

</details>

### 起動時のコンテンツ更新

Player は配信先のマニフェストを取得し、ファイルのサイズとハッシュを検証します。取得や検証に失敗した場合は、検証済みキャッシュまたは同梱コンテンツを使います。タイトル UI の準備完了後に、使用するキャッシュの記録を試みます。

<details>
<summary>中文对照</summary>

启动时获取服务器清单并校验文件大小和哈希。失败时使用已验证缓存或随包内容，标题 UI 就绪后再尝试提交活动缓存记录。

</details>
